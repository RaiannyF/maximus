# MAXIMUS

**Plataforma web para organização e acompanhamento da vida acadêmica dos estudantes da Universidade Federal de Viçosa (UFV).**

## Sobre o projeto

O MAXIMUS UFV é um projeto de interface web inspirado no sistema acadêmico Sapiens da UFV. A proposta é reunir informações acadêmicas em um só lugar, oferecendo ferramentas para auxiliar os estudantes na organização dos horários, no acompanhamento das disciplinas e no planejamento da graduação.

## Funcionalidades

- **Horário de aulas:** visualização semanal dos horários das disciplinas.
- **Disciplinas:** consulta de informações como ementas, créditos, carga horária, pré-requisitos e turmas.
- **Professores:** área destinada à consulta de informações dos professores.
- **Acerto de matrícula:** interface para auxiliar na organização de disciplinas e turmas durante o período de matrícula.
- **Histórico acadêmico:** acompanhamento do progresso acadêmico e das disciplinas concluídas, em andamento e pendentes.
- **Calendário:** visualização mensal de datas e eventos acadêmicos.
